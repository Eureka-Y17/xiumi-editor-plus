# 手机预览与公众号草稿服务

该服务为可选组件。普通编辑、自动保存、工程备份、HTML 和复制功能不需要它。

## 最少的启动步骤

1. 安装 [Node.js](https://nodejs.org/) 24 或更新版本。
2. 从 Releases 下载 `xiumi-editor-plus-0.4.0-local-service.zip`，解压到固定目录。
3. Windows 双击 `start-preview.cmd`。第一次需要联网安装运行依赖，之后直接启动。
4. 不要关闭服务窗口。在编辑台点「连接」，输入窗口显示的配对码，再点「连接本地服务」，允许扩展访问本机地址。
5. 使用二维码功能时，手机与电脑连接同一 Wi-Fi，选择可访问的局域网地址。服务窗口也会列出地址。

从源码或 macOS/Linux 启动：

```sh
npm ci
npm run bridge -- --lan
```

不加 `--lan` 时仅监听 127.0.0.1，适合仅本机的同步与测试，手机不能访问。加 `--lan` 才监听局域网接口；Windows 防火墙需要允许相应的本机服务访问。端口为 4318，配对连接始终通过 `http://127.0.0.1:4318`。

配对码只存浏览器当前会话，用于调用本机 API，不是公众号的 AppSecret。服务重启后配对码变化，需要重新连接。

## 二维码预览

「预览 / 二维码」→ 手机预览 → 选择手机可访问地址 →「生成预览二维码」。它创建随机地址的网页快照，1 小时过期，最多保留 10 份，也可以「撤销此预览」。后续编辑不会修改已经生成的快照，需要重新生成。

服务只在内存保存文章快照，关闭后全部消失。拿到链接且能访问该局域网的人可打开它；页面不暴露配对码和公众号凭据。它支持本地图片的 data URL，远程图片仍可能受防盗链或过期限制。

这是浏览器网页预览，不是微信官方预览码；未验证手机实机及微信渲染一致性。跨网络访问需要另行部署可信 HTTPS 服务，本版没有云托管、自动公网穿透或公开文章发布。

## 公众号连接与新建草稿

在公众号后台确认你拥有接口权限，并将电脑请求微信 API 时的**实际出口公网 IP**加入 IP 白名单。局域网地址不是出口 IP；账号类型及可用能力以当前公众号后台为准。

1. 「连接与同步」中填 AppID 与 AppSecret →「设置公众号连接」。不要把凭据发到聊天或提交仓库。
2. 选择本地 PNG/JPEG 封面，或填封面永久素材 ID / 图片 HTTPS 地址。地址方式会先上传为永久素材。作者可选。
3. 标题需 1–32 个字符，点击「一键同步到公众号草稿箱」。成功后显示草稿素材 ID。
4. 到公众号后台核对正文、图片和封面，再使用微信自己的手机预览；本助手不会群发或发布。

常规流程：本地叠放区合成 PNG → 本机服务获取调用凭据 → 上传正文图片并替换 URL → 必要时上传封面 → 新建草稿。AppSecret 和 access_token 仅留在本机服务内存，服务关闭后清除。前端不收到 access_token。

相同内容在服务运行期间重复点击会复用同一个请求/结果。图片上传失败或草稿请求超时后，请先检查公众号后台；重启服务会清空去重记录。更换账号也会清空去重状态。上传的素材不会自动清理，以免误删被草稿引用的图片。

**当前自动测试仅使用模拟微信响应；尚未完成真实账号同步验证。** 未配置凭据时不会假报同步成功。不支持直接回写秀米、覆盖原稿或发布公众号文章。

## 支持范围与错误说明

- 正文图片上传支持 PNG/JPEG/GIF，最大本地限制为 10 MB；微信可能对具体接口有更严格限制，请以返回错误为准。WebP 请先转换格式。
- 只允许服务下载公共 HTTPS 图片，拒绝环回、内网、保留 IP、非 HTTPS 及无限重定向。某些防盗链图片需要先下载并在编辑台替换。
- 尚未转图的绝对定位、SVG、视频/音频、背景图片会阻止同步，避免明知不兼容仍丢样式。
- 微信错误编号原样以数字显示，凭据与完整请求地址不写日志；请根据权限、IP、封面及图片格式排查。
- 本机 API 需要配对 Bearer 码，拒绝普通网页来源。预览页单独设置禁止脚本的内容策略。

官方参考入口：[调用凭据](https://developers.weixin.qq.com/doc/offiaccount/Basic_Information/getStableAccessToken.html)、[正文图片上传](https://developers.weixin.qq.com/doc/service/api/material/permanent/api_uploadimage)、[新增草稿](https://developers.weixin.qq.com/doc/service/api/draftbox/draftmanage/api_draft_add)。文档页面在本次环境中未能完整读取，接口实现以自动契约测试和后续真实账号验证为边界，未对所有账号类型作兼容声明。
