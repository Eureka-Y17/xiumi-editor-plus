# 测试记录 · 0.4.2 本地编辑台

## 自动验证通过

- TypeScript 严格类型检查、WXT MV3 构建。
- **73 项单元/集成测试，6 个文件**：原有 44 项操作、导入与范围测试；22 项本地编辑/工程/富文本测试；7 项本机 HTTP 服务测试。

本地编辑场景实际使用鼠标拖动把手，检查文字卡片 X/Y 变化与撤销重做；验证背景板和文字卡片置底后 z-index 变化、同级组合与取消组合、普通段落直接拖拽排序、选区加粗、应用文字、IndexedDB 刷新恢复、工程下载，以及交付副本合成 PNG 的剪贴板粘贴往返。工程中的原始画布在复制后仍保留。

单元测试额外覆盖：跨父层组合/循环移动拦截、锁定、复制不产生重复 DOM ID、属性值限制、表格单元格不可拖出、组合在带边距画布中的坐标换算、图片链接不破坏画布定位、富文本换行与执行内容清理、工程文件清理和格式限制。

本机服务测试覆盖配对失败、普通网页来源拦截、Unicode 不正确配对码的处理、无脚本预览、随机地址、过期/撤销、预览地址白名单、图片下载地址限制、缺凭据错误、图片 URL 替换、新建草稿去重及微信错误码。微信接口始终使用模拟响应，没有调用真实账号。

## 浏览器测试设置

Windows 本地使用 Node.js 24 与已安装 Edge 的临时独立配置。未读取用户既有浏览器会话，不开放网络调试端口。CI 固定 Ubuntu 24.04，使用 Playwright Chromium。

服务端到端测试为了避免自动化控制浏览器原生权限弹窗，在临时复制的扩展清单中预先授予 127.0.0.1 访问权；生产包仍采用用户点击连接时申请的**可选**本机权限。原生权限弹窗交互尚待手动确认。

二维码测试实际生成 PNG 二维码、请求本机预览网页并验证撤销后失效。测试地址为环回，不是手机扫码实测。公众号同步场景返回的 `mock-draft-id` 为模拟标识，不能作为真实接口兼容证明。

## 当前兼容范围

已测范围为普通 HTML 图文、常用文字样式、本地图片、列布局、表格文字、组合与本地自由叠放。SVG 互动、媒体编辑、完整模板/字体素材库、跨单元格合并及完整秀米功能复刻尚未支持。

交付图片保留叠放外观，但合成区域失去可编辑文字、内部链接/互动和动画。普通 HTML 的 CSS 仍可能被微信清理。任何正式公众号发布前都应以真实草稿和微信预览确认；本工具不自动发布。

## 旧版原生适配结论

0.3.0 用户截图证实结构树曾混入外壳，绿框落到素材栏。原生控制器返回不等于选区正确，更不等于保存可靠。0.4.0 已移除页面注入，旧版真实适配不列入当前兼容承诺。

补充：浏览器回归确认独立 iframe 预览保留编辑台的基础标题字号。选择框把手在新选区绘制前同步更新，修复切换工程后立即拖动可能沿用旧把手的问题。可选服务 ZIP 已实际解压，以 `npm ci --omit=dev --ignore-scripts` 安装 81 个运行包，并在临时环回端口启动、完成配对状态请求。

## 0.4.1 截图问题回归

新增自制「书单容器 + 横排推荐语 + 窄卡片」工程，前置 40 个段落。自动测试验证：点击正文展开并滚动树；普通无重叠层次禁用；插入段落和后插空行均在横排容器之后、正文宽度不缩小；恢复的阅读顺序按钮整体移动模板；窄卡片靠右实际改变坐标；属性输入框未改动时 Ctrl+Z 可撤销文章；八种经典色与颜色撤销；文字居中；未应用文本原生撤销不改文章。

1440×900 下逐一检查可用分类页和文字子页没有内容溢出。截图 `screenshots/studio-properties-tabs.png` 已目视检查。测试模板依据用户截图特征自制，并非用户原稿的 HTML；用户实际复杂模板仍需核对。

在用户授权提供的工程上，本机临时浏览器实际验证：弹性横线靠右前 X=628.5、靠右后 X=777.5，移动 149 CSS 像素，宽度不变；重复靠右提示已到位；Ctrl+Z 恢复原坐标。图书块可移到同级推荐语之后，块内 HTML 保持不变，撤销后整篇 HTML 与操作前一致。
