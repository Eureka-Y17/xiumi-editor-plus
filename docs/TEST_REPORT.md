运行环境为 Windows，Node.js 24.11.0。下载的 Chrome for Testing 在此机器出现 Windows SideBySide 启动错误，最终使用已安装 Edge 的隔离临时配置完成扩展验证，未读取用户现有浏览器会话。

Windows 本机遇到相同情况，可在 PowerShell 中指定已安装 Edge：

```powershell
$env:XEP_BROWSER_EXECUTABLE = 'C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe'
npm run test:e2e
```

CI 固定 Ubuntu 24.04，使用 Playwright Chromium；精确依赖版本由 lockfile 固定。CI 结果以仓库 Actions 对应提交为准。首次云端运行发现浮动的 ubuntu-latest 已升级到 Playwright 1.58 不支持的系统版本，现已固定运行器版本。

## 测试页面与截图的边界

`readonly-fixture.png` 来自拦截网络后提供的自制 `contenteditable` 隔离夹具。它证明扩展注入路径与只读保护有效，**不是秀米实际页面或真实站点适配证据**。

本地演示中的所有编辑都针对自制 HTML；尚未进行真实秀米保存、刷新或同步测试。

0.2.0 增加原生剪贴板回归：写入自制 HTML → 浏览器 Ctrl+V 导入 → 图片交换且保留尺寸 → 复制富文本 → 下载 HTML 备份。另验证局部推荐语外的书封识别、手动点选、范围扩大和 Esc 取消。测试使用自制夹具，不是用户截图推文的原始导出数据，也不等于公众号粘贴后的真机验证。

## 当前兼容承诺

可承诺自制演示、导入副本的已测操作和隔离夹具中的只读保护。Chrome / Edge 可安装 MV3 包，但秀米页面内直接写操作持续禁用，原生选中桥接真实测试失败已停用，原稿保存刷新未验证。导入内容的 SVG / 滑动 / 特殊结构限制修改；iframe 移除；合成图片无法恢复内部图层。公众号最终显示仍需真实预览。

## 开放真实编辑的门槛

每个操作独立记录秀米版本、自制测试稿和步骤，并通过「修改 → 原生继续编辑 → 撤销 → 保存 → 刷新 → 草稿同步 → 手机预览」。失败即保留禁用，不能把本地演示通过列为真实兼容通过。

## 0.3.0 补充验证

增加 8 项属性测试：计算样式背景识别、颜色与背景图片分离、容器含 SVG 时的属性与结构权限区分、格式和链接保留、换行与表情、文本注入防护及原生写操作拦截。浏览器回归增加背景简写下调色与撤销重做、文字编辑、原生接口不调用、活动页与空外壳过滤、点击文字高亮尺寸匹配、复制返回来源标签且正文保持不变。

原生选中自动测试使用模拟控制器，仅证明消息和调用链。另在用户登录的真实秀米测试窗口中找到 1 个正文根区域与 5 个组件，原生选中调用返回成功，但用户随后确认它框住整篇、无名节点高亮异常，结构树与正文不对应。该验证判定失败，已移除原生选中调用。修正过滤规则后的真实推文仍待复测，编辑保存与刷新恢复也未通过。独立验证窗口使用临时配置和本地进程通信，不开放网络调试端口。

截图确认第一节点覆盖画布；用户补充截图显示无名节点的绿框实际落在左侧素材栏。新增 3 项回归覆盖活动页选择、隐藏副本与编辑工具层过滤、透明空壳展平；连同属性测试共 44 项。端到端夹具新增多页及空壳，验证仅保留活动正文、选中段落高亮尺寸一致且不调用原生控制器。上述为复现夹具验证，不能代替用户真实推文复测。

针对补充截图增加几何范围过滤：正文容器内但渲染在纸张范围外的辅助副本不列入组件树。高亮宿主移至文档根节点，避免 body 位置变换引入另一套坐标。浏览器夹具包含移位 body 与落在素材栏的副本，验证正文节点高亮的 x、y、宽、高均对齐；真实秀米仍需更新扩展后复测。
